## Goal

Create a simple website where:

1. User enters a username.
2. User clicks `Submit`.
3. The username is inserted into my existing Supabase `users` table.
4. The website displays whether the operation succeeded or failed.

Before building the database integration, use the connected Supabase project and inspect the existing database.

Verify:

- The `public.users` table exists.
- The actual columns in the table.
- The datatype of the `username` column.
- Whether other columns have defaults or are required.

- Whether the current policies allow this application to INSERT into `public.users`.

Do NOT guess the database schema.

Do NOT create or modify tables, columns, RLS policies, or other database objects without asking me first.

## Build the Website

[ Submit ]

## Connect the Form to Supabase

Use the existing Supabase connection already configured in Lovable.

Use the official Supabase client.

When Submit is clicked:

1. Trim the username.
2. Validate that it is not empty.
3. Disable the Submit button while processing.
4. Insert the username into the existing `public.users` table.

The operation should be equivalent to:

```typescript id="uwi0hb"
const { error } = await supabase
  .from("users")
  .insert({
    username: username.trim()
  });
```
